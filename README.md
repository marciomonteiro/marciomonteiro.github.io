# marciomonteiro.github.io

Personal résumé of Marcio Monteiro, served with GitHub Pages at <https://marciomonteiro.github.io>.

The whole page lives in `index.html`; styles are in `static/css/`. To preview locally, run `./start_server.sh` (requires [Jekyll](https://jekyllrb.com/)) or open `index.html` directly.

Based on the [vitae](https://github.com/biomadeira/vitae) template by biomadeira (MIT License, see `LICENSE`).
